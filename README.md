# バンド ニューアルバム ティーザー動画

## 概要
バンドのニューアルバムリリースに向けたティーザー動画を制作するプロジェクト。

## 仕様
- 尺：約1分
- 素材：同時進行で開発中のゲームのアセットを流用して制作

## 関連プロジェクト
- ゲーム開発プロジェクト（素材の提供元）

---

## セリフ記法マニュアル

セリフ文字列に以下の記号を含めることで、表示の制御ができます。

| 記号 | 意味 | 例 |
|------|------|----|
| `\|` | ウェイト（約0.7秒の一時停止） | `やあ！\|えっと…` |
| `\n` | 強制改行 | `1行目\n2行目` |

### 使用例

```js
{ text: 'ほんとうに？\|すごい！', ... }
// →「ほんとうに？」の後に一時停止してから「すごい！」が出る

{ text: 'モリタサキ・イン・ザ・プールの\nニューアルバムがでるんだって！', ... }
// → 1行目と2行目が強制的に改行される
```

### 注意
- `|` と `\n` は画面には表示されません
- 自動折り返しも引き続き有効です（`\n` と併用可）
